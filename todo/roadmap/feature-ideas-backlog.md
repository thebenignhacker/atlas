A backlog of Atlas features that would help a solo founder track all work in one place. Promote each to its own card when picked up.

## Ideas
- **Deadline radar.** A unified, time-sorted view of every time-sensitive item across all projects. The IETF cutoff would have surfaced here automatically. Date/cron fields on todos feed a "next 7 / 30 days" board.
- **Waiting-on tracker.** Items blocked on other people (CNA onboarding call, MITRE reply, upstream PR merges) with a "last nudged" date and a follow-up nudge. Distinct from internal `Depends`.
- **Needs-my-decision queue.** Surface open decisions across projects (e.g., the did:opena2a pct-encode call) so none sits silently.
- **Deploy / release tracker.** Which repos have merged-but-undeployed or ready-but-unmerged changes (e.g., the Atlas epic/story branch not yet deployed). "What is shipped vs what is live."
- **Weekly digest.** Auto "what shipped this week" across repos (merged PRs, filed drafts, completed todos). Atlas already collects activity; roll it into a digest.
- **Contacts / relationships.** People and orgs in flight (Red Hat root, MITRE ATT&CK, W3C CCG, design partners) with status and last touch.
- **Reference dashboard.** The load-bearing external links and endpoints in one place (datatracker docs, cveform, api.oa2a.org endpoints, registry URLs).
- **Announcements / marketing tracker.** Already filed as its own card (`feature-announcements-tracker`).
